# ChefMarket

Mobil öncelikli yemek ve market oyunu.

## İlk prototip
- Türk, İtalyan ve Kore mutfağı seçimi
- Menü kategorileri
- Responsive mobil arayüz
- PWA manifest altyapısı

## Çalıştırma
```bash
npm install
npm run dev
```

Sonraki aşama: yemek seçimi, market rafları, sürükle-bırak sepet ve tarif doğrulama mekaniği.
